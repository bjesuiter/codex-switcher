# Function: merge() [​](https://gunshi.dev/api/combinators/functions/merge#function-merge)
## Call Signature [​](https://gunshi.dev/api/combinators/functions/merge#call-signature)
ts```
function merge<A, B>(a, b): Omit<A, keyof B> & B;
```

**`Experimental`**
Compose multiple [Args](https://gunshi.dev/api/default/interfaces/Args) schemas into one.
On key conflicts the later schema wins (last-write-wins).
### Type Parameters [​](https://gunshi.dev/api/combinators/functions/merge#type-parameters)
Type Parameter | Description  
---|---  
`A` _extends_ [`Args`](https://gunshi.dev/api/default/interfaces/Args) | First schema type.  
`B` _extends_ [`Args`](https://gunshi.dev/api/default/interfaces/Args) | Second schema type.  
### Parameters [​](https://gunshi.dev/api/combinators/functions/merge#parameters)
Parameter | Type | Description  
---|---|---  
`a` | `A` | First schema.  
`b` | `B` | Second schema.  
### Returns [​](https://gunshi.dev/api/combinators/functions/merge#returns)
`Omit`<`A`, keyof `B`> & `B`
A merged schema containing all fields.
### Example [​](https://gunshi.dev/api/combinators/functions/merge#example)
ts```
const common = args({ verbose: boolean() })
const network = args({ host: required(string()), port: withDefault(integer(), 8080) })
const schema = merge(common, network)
```
