# Plugin List [​](https://gunshi.dev/guide/plugin/list#plugin-list)
Gunshi provides official plugins that address common CLI development needs. See [Using Plugins](https://gunshi.dev/guide/plugin/getting-started) for how to use plugins in your application.
## Official Plugins [​](https://gunshi.dev/guide/plugin/list#official-plugins)
###  [@gunshi/plugin-global](https://github.com/kazupon/gunshi/tree/main/packages/plugin-global) [​](https://gunshi.dev/guide/plugin/list#gunshi-plugin-global)
Adds global `--help` and `--version` options to all commands.
###  [@gunshi/plugin-renderer](https://github.com/kazupon/gunshi/tree/main/packages/plugin-renderer) [​](https://gunshi.dev/guide/plugin/list#gunshi-plugin-renderer)
Provides default rendering for usage, help text, and validation errors.
###  [@gunshi/plugin-i18n](https://github.com/kazupon/gunshi/tree/main/packages/plugin-i18n) [​](https://gunshi.dev/guide/plugin/list#gunshi-plugin-i18n)
Provides internationalization support for CLI applications.
###  [@gunshi/plugin-completion](https://github.com/kazupon/gunshi/tree/main/packages/plugin-completion) [​](https://gunshi.dev/guide/plugin/list#gunshi-plugin-completion)
Provides shell completion functionality for bash, zsh, and fish.
## Community Plugins [​](https://gunshi.dev/guide/plugin/list#community-plugins)
NOTE
Welcome your plugins! Submit a PR to add your plugin to this list.
## Where to Go From Here [​](https://gunshi.dev/guide/plugin/list#where-to-go-from-here)
  * **Use official plugins** : Integrate these plugins into your CLI applications for enhanced functionality
  * **Study implementations** : Review the source code of official plugins to learn implementation patterns
  * **Create your own** : Apply what you've learned to build custom plugins for your specific needs
  * **Share with the community** : Publish your plugins and submit a PR to add them to this list
